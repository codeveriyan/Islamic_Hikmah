# Islamic Hikmah

Islamic Hikmah is a modern Islamic mobile app with a FastAPI backend and an Expo React Native frontend.

## Features
- Fatawa search and dynamic ruling synthesis
- Daily Dhikr and Hajj/Umrah guides
- Quran ASR (Automatic Speech Recognition) verse identification
- Real-time prayer times and Hijri calendar

## Architecture
- **Backend:** Python / FastAPI / MongoDB
- **Frontend:** React Native / Expo
- **AI/ML:** Local Whisper ASR inference (PyTorch)
